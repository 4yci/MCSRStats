Rank icons
==========

The six MCSR Ranked rank badges used across the site (leaderboard, profiles,
head-to-head). They were sliced from the official rank sprite sheet — the
highest sub-tier of each rank — and kept on a shared square canvas so their
relative sizes stay faithful (a coal badge really is smaller than a netherite
one).

  coal.png  iron.png  gold.png  emerald.png  diamond.png  netherite.png

If a file is missing, that rank automatically falls back to the app's built-in
pixel-art icon, so nothing breaks.

Note: Minecraft and MCSR Ranked assets are the property of Mojang Studios /
Microsoft and the MCSR Ranked project. They are used here for identification in
a non-commercial fan project; keep the attribution shown in the Info panel.
